# Method outputs

The assignment requires one CSV per method:

- `method1_programmatic.csv`
- `method2_low_cost.csv`
- `method3_expensive.csv`
- `method4_refined.csv`

These files are generated by the scripts in `methods/`.

Method 1 has already been tested locally on all 50 invoices. Methods 2–4 should be generated only after a real OpenAI API key is configured, so their results and token-cost figures are genuine.

After all four methods have run, execute:

```bash
python evaluation/compare_results.py
python scripts/calculate_costs.py
python scripts/build_db.py
```
